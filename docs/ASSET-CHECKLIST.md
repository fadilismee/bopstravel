# Asset checklist

- [ ] Approved logo (SVG preferred; transparent PNG fallback), favicon, brand usage rules.
- [ ] Original hero image showing the actual service / fleet, with publication rights.
- [ ] Per-vehicle original photos, compressed responsive variants, accurate captions and alt text.
- [ ] Optional route/location imagery licensed for commercial use; record source/license.
- [ ] Social preview image (1200×630), brand-safe and legible.
- [ ] Font licenses and local font files if using non-system typefaces.
- [ ] Written approval for customer photos, testimonials, and staff portraits.

Do not download or reuse assets from the reference website without explicit permission. Store source/license notes beside each asset or in an asset manifest. Optimize images to AVIF/WebP where supported, retain suitable fallbacks, and avoid oversized originals in the served site.
